# FM-TransUNet and SteelOM2SEM

This public repository is the planned release location for **FM-TransUNet**, a supervised model for optical-to-SEM image translation of steel microstructures, and the expanded **SteelOM2SEM** dataset of registered optical and scanning electron microscopy image pairs.

## Release status

The FM-TransUNet implementation, complete dataset, and associated metadata are pending release. This page currently contains release information.

The [earlier SteelOM2SEM repository](https://github.com/YixiaoOneSmile/PI-TransUNet-SteelOM2SEM) hosts the original public subset and its baseline code.
